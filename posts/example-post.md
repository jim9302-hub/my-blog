# 환영합니다

이 블로그는 **마크다운 파일**을 읽어서 정적 페이지로 변환합니다.
프레임워크 없이 순수 HTML, CSS, JavaScript로 만들어졌습니다.

## 지원하는 기능

- 다크 모드 (시스템 설정 감지 + 수동 토글)
- 모바일 반응형 레이아웃
- 코드 블록, 인용문, 목록 등 기본 마크다운 문법

```js
function hello() {
  console.log("hello, blog");
}
```

> 새 글을 쓰려면 `posts/` 폴더에 `.md` 파일을 추가하고
> `node scripts/build-index.mjs`를 실행하세요.
